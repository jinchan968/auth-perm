## 新增需求

### 需求:租户详情页禁用按钮
租户详情页必须提供禁用/启用按钮，允许管理员启用或禁用租户。

#### 场景:显示禁用按钮
- **当** 租户状态为 active 时
- **那么** 显示"禁用"按钮

#### 场景:显示启用按钮
- **当** 租户状态为 suspended 时
- **那么** 显示"启用"按钮

#### 场景:禁用租户
- **当** 管理员点击禁用按钮
- **那么** 系统调用禁用 API，刷新页面显示

#### 场景:启用租户
- **当** 管理员点击启用按钮
- **那么** 系统调用启用 API，刷新页面显示
