# 移动租户禁用按钮到详情页

## 为什么

当前租户列表页显示禁用/启用按钮，不符合用户操作习惯。禁用/启用操作应该在租户详情页进行，列表页只展示租户基本信息和操作入口。

## 变更内容

1. 移除租户列表页的禁用/启用按钮
2. 在租户详情页添加禁用/启用按钮，根据租户状态动态显示

## 功能 (Capabilities)

### 新增功能
- `tenant-detail-disable-button`: 租户详情页禁用按钮

### 修改功能
- `tenant-list-page`: 移除列表页的禁用/启用按钮

## 影响

- **前端页面**: ui/app/tenants/page.tsx（列表页）
- **前端页面**: ui/app/tenants/[id]/page.tsx（详情页）
