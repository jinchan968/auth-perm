## 上下文

当前租户、权限、角色的创建需要前端传入 code 字段。code 格式应为"前缀+6位数字"，如 T000001、P000001、R000001。

## 目标 / 非目标

**目标：**
- 后端在创建租户/权限/角色时自动生成 code
- 前端表单移除 code 输入框
- 复用已有的 code_gen 包

**非目标：**
- 不修改现有查询接口的 code 返回
- 不修改 code 的格式规范

## 决策

### 后端实现
1. 在各服务中注入 code_gen.CodeGenerator
2. 创建服务时调用 GenerateCodeWithDB 自动生成 code
3. 前缀映射：
   - 租户（Tenant）: T
   - 权限（Permission）: P
   - 角色（Role）: R

### 前端实现
1. 移除租户创建表单的 code 输入框
2. 移除权限创建表单的 code 输入框
3. 移除角色创建表单的 code 输入框

## 风险 / 权衡

- 并发生成：code_gen 已支持 Redis 分布式锁，安全性有保障
- 兼容性：现有 code 字段可保留但设为可选
