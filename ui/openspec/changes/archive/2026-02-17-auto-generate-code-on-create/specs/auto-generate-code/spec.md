## 新增需求

### 需求:创建实体时自动生成Code
系统必须在创建租户、权限、角色时自动生成 code，不需要用户手动输入。

#### 场景:创建租户时自动生成Code
- **当** 调用创建租户接口且不传入 code
- **那么** 后端自动生成 code，格式为 T + 6位数字（如 T000001）

#### 场景:创建权限时自动生成Code
- **当** 调用创建权限接口且不传入 code
- **那么** 后端自动生成 code，格式为 P + 6位数字（如 P000001）

#### 场景:创建角色时自动生成Code
- **当** 调用创建角色接口且不传入 code
- **那么** 后端自动生成 code，格式为 R + 6位数字（如 R000001）

#### 场景:前端创建表单不显示Code输入框
- **当** 用户打开租户/权限/角色创建页面
- **那么** 表单不显示 code 输入框，code 由后端自动生成
