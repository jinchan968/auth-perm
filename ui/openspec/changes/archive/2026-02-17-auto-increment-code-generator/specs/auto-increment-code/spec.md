## 新增需求

### 需求:Code生成器服务
系统必须提供一个公共方法来生成自增的 code，格式为"前缀+6位数字"。

#### 场景:生成下一个自增Code
- **当** 调用 GenerateCode(currentMaxCode, prefix) 方法
- **那么** 返回格式为 prefix + 6位数字的下一个自增码

#### 场景:当前最大Code为空
- **当** currentMaxCode 为空字符串
- **那么** 返回 prefix + "000001"

#### 场景:提取当前数字并自增
- **当** currentMaxCode 为 "P000025"
- **那么** 返回 "P000026"

#### 场景:达到999999后循环
- **当** currentMaxCode 为 "P999999"
- **那么** 返回 "P000001"

#### 场景:使用Redis缓存
- **当** Redis 可用
- **那么** 使用 Redis 存储当前最大码实现分布式锁

#### 场景:Redis不可用降级
- **当** Redis 不可用
- **那么** 使用内存缓存作为降级方案
