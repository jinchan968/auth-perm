## 新增需求

### 需求:角色权限分配
系统必须能够为角色分配或撤销权限。

#### 场景:查看角色权限
- **当** 用户点击角色的"分配权限"按钮
- **那么** 系统必须展示该角色当前已分配的权限列表，以及所有可分配的权限列表

#### 场景:分配权限给角色
- **当** 用户勾选某个权限后点击保存
- **那么** 系统必须调用后端API将权限分配给角色，成功后显示成功提示

#### 场景:撤销角色权限
- **当** 用户取消勾选某个已分配的权限后点击保存
- **那么** 系统必须调用后端API从角色撤销该权限，成功后显示成功提示

#### 场景:批量分配权限
- **当** 用户勾选多个权限后点击保存
- **那么** 系统必须一次性将所有选中的权限分配给角色
