## 新增需求

### 需求:角色列表展示
系统必须能够展示当前租户下的所有角色。

#### 场景:查看角色列表
- **当** 用户访问 /permissions/roles 页面
- **那么** 系统必须展示当前租户的所有角色，包括角色名称、描述、关联的权限数量、创建时间

#### 场景:角色搜索
- **当** 用户在角色列表页面输入搜索关键词
- **那么** 系统必须根据角色名称或描述进行模糊匹配过滤

### 需求:创建角色
系统必须能够创建新的角色。

#### 场景:创建新角色
- **当** 用户点击"新建角色"按钮，填写角色名称、描述后点击保存
- **那么** 系统必须调用后端API创建角色，成功后跳转到角色列表页

### 需求:编辑角色
系统必须能够编辑已有角色的信息。

#### 场景:编辑角色信息
- **当** 用户点击角色的编辑按钮，修改角色信息后点击保存
- **那么** 系统必须调用后端API更新角色，成功后刷新页面显示

### 需求:删除角色
系统必须能够删除角色。

#### 场景:删除角色
- **当** 用户点击角色的删除按钮，确认删除操作
- **那么** 系统必须调用后端API删除角色，成功后刷新列表
