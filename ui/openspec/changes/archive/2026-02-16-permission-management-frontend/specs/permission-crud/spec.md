## 新增需求

### 需求:创建权限
系统必须能够创建新的权限。

#### 场景:创建新权限
- **当** 用户点击"新建权限"按钮，填写权限名称、代码、描述、资源等信息后点击保存
- **那么** 系统必须调用后端API创建权限，成功后跳转到权限列表页

#### 场景:创建权限时租户隔离
- **当** 用户创建权限时
- **那么** 系统必须自动将当前登录用户的租户ID关联到权限

### 需求:编辑权限
系统必须能够编辑已有权限的信息。

#### 场景:编辑权限信息
- **当** 用户点击权限的编辑按钮，修改权限信息后点击保存
- **那么** 系统必须调用后端API更新权限，成功后刷新页面显示

#### 场景:禁止编辑系统权限
- **当** 用户尝试编辑 is_system=true 的权限
- **那么** 系统必须禁止编辑并显示提示信息

### 需求:删除权限
系统必须能够删除权限。

#### 场景:删除权限
- **当** 用户点击权限的删除按钮，确认删除操作
- **那么** 系统必须调用后端API删除权限，成功后刷新列表

#### 场景:禁止删除系统权限
- **当** 用户尝试删除 is_system=true 的权限
- **那么** 系统必须禁止删除并显示提示信息
