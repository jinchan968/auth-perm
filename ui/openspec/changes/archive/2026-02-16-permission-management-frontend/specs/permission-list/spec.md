## 新增需求

### 需求:权限列表展示
系统必须能够展示当前租户下的所有权限列表。

#### 场景:查看权限列表
- **当** 用户访问 /permissions 页面
- **那么** 系统必须展示当前租户的所有权限，包括权限名称、代码、描述、资源类型、是否系统权限、状态

#### 场景:权限搜索
- **当** 用户在权限列表页面输入搜索关键词
- **那么** 系统必须根据权限名称或代码进行模糊匹配过滤

#### 场景:分页展示
- **当** 权限数量超过单页显示限制
- **那么** 系统必须支持分页展示，每页显示 10 条记录

### 需求:权限详情查看
系统必须能够展示单个权限的详细信息。

#### 场景:查看权限详情
- **当** 用户点击权限列表中的某个权限
- **那么** 系统必须跳转到权限详情页面，展示该权限的完整信息
