## 新增需求

### 需求:用户角色分配
系统必须能够为用户分配或撤销角色。

#### 场景:查看用户角色
- **当** 用户访问 /permissions/users 页面，点击某个用户的"分配角色"按钮
- **那么** 系统必须展示该用户当前已分配的角色列表，以及所有可分配的角色列表

#### 场景:分配角色给用户
- **当** 用户勾选某个角色后点击保存
- **那么** 系统必须调用后端API将角色分配给用户，成功后显示成功提示

#### 场景:撤销用户角色
- **当** 用户取消勾选某个已分配的角色后点击保存
- **那么** 系统必须调用后端API从用户撤销该角色，成功后显示成功提示

#### 场景:查看租户下的用户列表
- **当** 用户访问 /permissions/users 页面
- **那么** 系统必须展示当前租户下的用户列表，包括用户名、邮箱、已分配角色数量
