## 上下文

当前角色列表 API 只返回角色基本信息（id、code、name、description、is_active 等），没有包含每个角色关联的权限数量。前端角色列表页面因此无法展示角色的权限配置情况。

## 目标 / 非目标

**目标：**
- 在角色列表 API 响应中增加每个角色的权限数量
- 在前端角色列表表格中显示权限数量列

**非目标：**
- 显示权限名称列表（仅显示数量）
- 修改权限详情页面

## 决策

### 方案 A：在查询角色列表时关联统计权限数量
- 优点：一次查询获取所有数据
- 缺点：SQL 复杂度增加

### 方案 B：先查询角色列表，再单独查询每个角色的权限数量
- 优点：实现简单
- 缺点：N+1 查询问题，性能差

**选择方案 A**，使用 SQL 子查询或 JOIN 统计权限数量。

### 前端实现
- 在角色列表表格中添加"权限数量"列
- 显示格式：数字（如：5）或"无"

## 风险 / 权衡

- 性能：大量角色时可能需要优化索引
- 兼容：API 响应格式变化需要同步更新前端类型定义
