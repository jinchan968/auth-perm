## 修改需求

### 需求:获取角色详情必须验证租户

系统必须在获取角色详情时验证该角色是否属于当前租户。

#### 场景:获取其他租户的角色
- **当** 用户通过 API 调用 GET /permissions/roles/{id}，但角色不属于当前租户
- **那么** 系统必须返回 403 错误，拒绝访问

### 需求:更新角色必须验证租户

系统必须在更新角色时验证该角色是否属于当前租户。

#### 场景:更新其他租户的角色
- **当** 用户通过 API 调用 PUT /permissions/roles/{id} 更新角色，但角色不属于当前租户
- **那么** 系统必须返回 403 错误，拒绝更新

### 需求:删除角色必须验证租户

系统必须在删除角色时验证该角色是否属于当前租户。

#### 场景:删除其他租户的角色
- **当** 用户通过 API 调用 DELETE /permissions/roles/{id} 删除角色，但角色不属于当前租户
- **那么** 系统必须返回 403 错误，拒绝删除
