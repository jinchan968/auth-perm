## 修改需求

### 需求:获取角色权限必须验证租户

系统必须在获取角色权限时验证该角色是否属于当前租户。

#### 场景:获取其他租户角色的权限
- **当** 用户通过 API 调用 GET /permissions/roles/{id}/permissions，但角色不属于当前租户
- **那么** 系统必须返回 403 错误，拒绝访问

### 需求:移除角色权限必须验证租户

系统必须在移除角色权限时验证该角色是否属于当前租户。

#### 场景:移除其他租户角色的权限
- **当** 用户通过 API 调用 DELETE /permissions/roles/{id}/permissions/{permissionId}，但角色不属于当前租户
- **那么** 系统必须返回 403 错误，拒绝操作
