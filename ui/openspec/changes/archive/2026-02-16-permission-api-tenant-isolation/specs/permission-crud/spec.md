## 修改需求

### 需求:获取权限详情必须验证租户

系统必须在获取权限详情时验证该权限是否属于当前租户。

#### 场景:获取其他租户的权限
- **当** 用户通过 API 调用 GET /permissions/{id}，但权限不属于当前租户
- **那么** 系统必须返回 403 错误，拒绝访问

### 需求:更新权限必须验证租户

系统必须在更新权限时验证该权限是否属于当前租户。

#### 场景:更新其他租户的权限
- **当** 用户通过 API 调用 PUT /permissions/{id} 更新权限，但权限不属于当前租户
- **那么** 系统必须返回 403 错误，拒绝更新

### 需求:删除权限必须验证租户

系统必须在删除权限时验证该权限是否属于当前租户。

#### 场景:删除其他租户的权限
- **当** 用户通过 API 调用 DELETE /permissions/{id} 删除权限，但权限不属于当前租户
- **那么** 系统必须返回 403 错误，拒绝删除
