## 新增需求

### 需求:页面标题格式
所有页面必须使用统一的标题格式 `{页面名称} - Auth-Perm}`。

#### 场景:首页标题
- **当** 用户访问首页 `/home`
- **那么** 页面标题显示为 `Auth-Perm`

#### 场景:列表页标题
- **当** 用户访问列表页（如 `/permissions`）
- **那么** 页面标题显示为 `权限列表 - Auth-Perm`

#### 场景:详情页标题
- **当** 用户访问详情页（如 `/permissions/[id]`）
- **那么** 页面标题显示为 `权限详情 - Auth-Perm`

### 需求:页面标题位置
页面标题必须显示在页面顶部，使用 `<h1>` 标签。

#### 场景:标题可见性
- **当** 用户打开任意页面
- **那么** 页面标题在视口顶部可见

### 需求:面包屑导航
面包屑导航必须与页面标题保持一致。

#### 场景:面包屑与标题一致
- **当** 用户在权限列表页
- **那么** 面包屑显示 "首页 > 权限管理 > 权限列表"，与页面标题 "权限列表" 一致
