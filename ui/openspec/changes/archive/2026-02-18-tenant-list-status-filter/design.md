# 租户列表状态过滤 - 技术设计

## 上下文

在权限和角色管理页面，需要根据租户状态过滤租户列表。

## 目标 / 非目标

**目标：**
- 后端接口支持可选 status 参数
- 权限/角色页面添加状态过滤勾选框

**非目标：**
- 不修改租户列表页面（保持显示全部）

## 决策

### 后端实现
- 修改 List 方法：当 status 参数为空时，默认添加 status = active 条件
- 当 status 参数有值时，使用传入的值

### 前端实现
- 权限页面和角色详情页添加 Checkbox 组件
- 使用 React state 控制是否过滤 active 状态
- 调用 listTenants 时传入/不传入 status 参数

## 风险 / 权衡

- 兼容性：现有调用不传 status 的代码会自动改为只显示 active，需要评估影响
