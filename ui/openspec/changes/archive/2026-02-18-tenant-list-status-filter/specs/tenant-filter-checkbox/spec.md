## 新增需求

### 需求:权限/角色页面租户过滤勾选框
在权限和角色管理页面，租户下拉框上方必须显示"显示全部租户"勾选框。

#### 场景:默认只显示 active 租户
- **当** 用户打开权限/角色管理页面
- **那么** 租户下拉框只显示 active 状态的租户

#### 场景:勾选显示全部租户
- **当** 用户勾选"显示全部租户"
- **那么** 租户下拉框显示所有状态的租户

#### 场景:取消勾选
- **当** 用户取消勾选"显示全部租户"
- **那么** 租户下拉框恢复只显示 active 状态的租户
