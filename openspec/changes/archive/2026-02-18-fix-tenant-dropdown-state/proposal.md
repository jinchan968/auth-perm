# 修复前端租户下拉状态未同步问题

## 为什么

当前前端在租户下拉切换时，虽然 UI 展示了新租户，但传递给后端的 `tenant_id` 参数仍然使用的是之前选中的租户 ID。这导致后端接口调用时使用了错误的租户上下文，引发权限验证失败。

## 变更内容

1. 检查前端租户下拉组件的状态管理逻辑
2. 确保切换租户时同步更新所有相关的 `tenant_id` 状态变量
3. 确保 API 请求使用最新的 tenant_id

## 功能 (Capabilities)

### 新增功能
- `tenant-state-sync`: 租户切换时状态同步

## 影响

- **前端代码**: 修改租户下拉组件及相关状态管理
