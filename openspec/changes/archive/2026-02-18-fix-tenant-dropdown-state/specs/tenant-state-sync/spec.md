# 租户状态同步

## 新增需求

### 需求:租户切换时状态同步
当用户切换租户下拉选项时，系统必须确保所有使用 tenant_id 的地方都使用最新的值。

#### 场景:切换租户
- **当** 用户在租户下拉中选择一个新租户
- **那么** 所有 API 请求中的 tenant_id 参数必须使用新选择的租户 ID

#### 场景:组件使用租户上下文
- **当** 组件需要使用 tenant_id
- **那么** 组件必须从统一的租户上下文获取，而不是使用本地状态
