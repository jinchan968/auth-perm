## 上下文

当前租户管理页面点击"新建租户"按钮会跳转到独立的 `/tenants/new` 页面，用户需要离开当前列表页面，体验不够流畅。同时，原新建页面中的返回按钮颜色设计存在问题，需要优化。

## 目标 / 非目标

**目标：**
- 将新建租户改为 Modal 弹窗方式，在列表页直接创建
- 优化按钮样式，解决颜色问题
- 保持与现有 UI 风格一致

**非目标：**
- 不修改后端 API
- 不改变租户创建的数据结构和验证逻辑

## 决策

1. **使用现有 Dialog 组件**：项目已集成 shadcn/ui，使用其 Dialog 组件实现 Modal
2. **表单复用**：新建表单逻辑与现有 `/tenants/new` 页面保持一致，仅调整展示方式
3. **关闭行为**：Modal 关闭时不保存数据，提供明确的取消按钮

## 风险 / 权衡

- 无重大风险
- 保留 `/tenants/new` 页面作为备选访问方式
