## 新增需求

### 需求:租户创建 Modal 弹窗
系统必须在租户列表页面提供 Modal 弹窗方式创建新租户，用户无需离开当前页面。

#### 场景:点击新建按钮打开 Modal
- **当** 用户在租户列表页面点击"新建租户"按钮
- **那么** 系统显示 Modal 弹窗，标题为"新建租户"

#### 场景:填写表单并提交
- **当** 用户在 Modal 中填写租户名称、租户代码、套餐，并点击"创建"按钮
- **那么** 系统调用创建 API，成功后关闭 Modal 并刷新列表

#### 场景:取消创建
- **当** 用户在 Modal 中点击"取消"按钮或 Modal 外部区域
- **那么** 系统关闭 Modal，不提交数据

#### 场景:表单验证失败
- **当** 用户未填写必填字段（名称、代码）就点击"创建"
- **那么** 系统显示验证错误提示，不关闭 Modal

#### 场景:API 调用失败
- **当** 创建租户 API 返回错误
- **那么** 系统显示错误消息，Modal 保持打开状态

### 需求:Modal 样式设计
Modal 必须使用清晰、专业的视觉设计，按钮颜色必须符合整体 UI 风格。

#### 场景:按钮颜色
- **当** 用户查看 Modal 中的按钮
- **那么** 确认按钮使用主题色（蓝色渐变），取消按钮使用中性灰色
