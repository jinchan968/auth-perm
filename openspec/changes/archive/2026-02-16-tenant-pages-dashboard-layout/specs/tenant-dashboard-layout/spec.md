## 新增需求

### 需求:租户列表页仪表盘布局
租户列表页必须使用与仪表盘一致的布局结构。

#### 场景:显示布局
- **当** 用户访问租户列表页
- **那么** 显示头部（页面标题 + 头像）、左侧菜单、内容区（面包屑 + 列表）
