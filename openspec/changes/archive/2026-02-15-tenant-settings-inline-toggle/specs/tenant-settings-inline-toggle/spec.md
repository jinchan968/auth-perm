## 新增需求

### 需求:设置区域切换
租户详情页的功能开关和配额区域必须在查看态和编辑态之间切换。

#### 场景:点击设置按钮
- **当** 用户点击设置按钮
- **那么** 功能开关和配额区域从查看态切换到编辑态

#### 场景:编辑功能开关
- **当** 在编辑态下用户点击功能开关
- **那么** 显示 Switch 组件，可以切换开关

#### 场景:编辑配额
- **当** 在编辑态下用户编辑配额
- **那么** 显示 Input 组件，可以输入数字

#### 场景:保存设置
- **当** 用户在编辑态下点击保存
- **那么** 调用保存 API，成功后切换回查看态
