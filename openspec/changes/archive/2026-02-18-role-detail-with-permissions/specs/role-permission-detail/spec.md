# 角色详情权限展示

## 新增需求

### 需求:角色详情接口返回全量权限列表
角色详情接口必须返回当前租户下的所有权限列表，每个权限必须包含 `is_selected` 标记表示是否已关联到该角色。

#### 场景:获取角色详情
- **当** 用户调用 `GET /api/v1/permissions/roles/:id` 获取角色详情
- **那么** 系统返回角色基本信息，同时返回全量权限列表，每个权限包含 `is_selected` 字段

#### 场景:已关联权限标记为已选
- **当** 角色已关联某个权限
- **那么** 该权限的 `is_selected` 必须为 `true`

#### 场景:未关联权限标记为未选
- **当** 角色未关联某个权限
- **那么** 该权限的 `is_selected` 必须为 `false`

### 需求:保持向后兼容
接口返回结构必须包含原有的所有字段，仅增加新字段，不影响现有前端集成。

#### 场景:返回结构兼容
- **当** 客户端使用原有字段
- **那么** 不影响原有功能，新字段可忽略
