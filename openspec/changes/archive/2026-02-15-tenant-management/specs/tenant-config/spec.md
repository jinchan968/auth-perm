# tenant-config 规范

## 新增需求

### 需求:租户配置可以被更新
系统必须支持更新租户的配置信息。

#### 场景:更新功能开关
- **当** 管理员提交功能开关配置
- **那么** 系统更新租户的功能开关设置

#### 场景:更新配额限制
- **当** 管理员提交用户配额、API配额等限制
- **那么** 系统更新租户的配额限制

#### 场景:更新套餐
- **当** 管理员变更租户套餐
- **那么** 系统更新租户套餐信息

### 需求:租户配置可以被查询
系统必须支持查询租户的当前配置。

#### 场景:查询租户配置
- **当** 管理员请求查看租户配置
- **那么** 系统返回租户的完整配置信息
