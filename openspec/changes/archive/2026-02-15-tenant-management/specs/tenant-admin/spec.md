# tenant-admin 规范

## 新增需求

### 需求:可以分配租户管理员
系统必须支持将用户设置为租户管理员。

#### 场景:分配租户管理员
- **当** 超级管理员将某个用户分配为租户管理员
- **那么** 该用户获得租户级别的管理权限

#### 场景:移除租户管理员
- **当** 超级管理员移除某用户的租户管理员身份
- **那么** 该用户失去租户级别的管理权限

### 需求:租户管理员可以管理租户内资源
租户管理员必须能够管理其所属租户内的资源。

#### 场景:租户管理员查看租户用户
- **当** 租户管理员请求查看租户用户列表
- **那么** 系统返回该租户的用户列表

#### 场景:租户管理员管理租户角色
- **当** 租户管理员创建/修改/删除租户内的角色
- **那么** 系统执行相应操作并返回结果
