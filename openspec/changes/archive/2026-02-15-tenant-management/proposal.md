# 租户管理 Proposal

## 为什么

当前系统虽然通过 `accounts` 表的 `tenant_id` 字段支持多租户，但缺乏独立的租户管理功能。需要建立完整的租户领域，实现租户配置、计费、限制等企业级功能。

## 变更内容

1. **新增租户领域模型**：创建租户领域（tenant domain），包含租户实体和配置
2. **租户 CRUD**：实现租户的创建、查询、更新、删除
3. **租户配置管理**：管理租户的功能开关、配额限制
4. **租户管理员**：支持租户级别的管理员角色

## 功能 (Capabilities)

### 新增功能

- **tenant-core**: 租户核心功能 - 租户的创建、查询、更新、删除
- **tenant-config**: 租户配置管理 - 功能开关、配额限制
- **tenant-admin**: 租户管理员 - 租户级别的管理员管理

### 修改功能

- (无)

## 影响

- 需要在 `internal/domain` 下创建新的 `tenant` 领域
- 需要创建对应的 repo、service、handler
- 需要在 container 中注册新的依赖
- 需要添加新的路由
