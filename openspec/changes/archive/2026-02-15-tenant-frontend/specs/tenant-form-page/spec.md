# tenant-form-page 规范

## 新增需求

### 需求:创建租户表单必须包含必要字段
系统必须提供创建租户的表单，包含名称、代码、套餐等字段。

#### 场景:填写创建表单
- **当** 用户填写租户名称、代码并选择套餐
- **那么** 系统验证输入并提交创建请求

### 需求:创建租户表单必须验证输入
系统必须验证表单输入的有效性。

#### 场景:验证必填字段
- **当** 用户未填写必填字段就提交
- **那么** 系统显示错误提示，要求填写必填字段

### 需求:编辑租户表单必须预填充数据
系统必须预填充要编辑的租户数据。

#### 场景:编辑租户
- **当** 用户进入编辑页面
- **那么** 系统显示该租户现有数据供修改

### 需求:编辑租户表单必须验证代码唯一性
系统必须验证租户代码的唯一性（排除自身）。

#### 场景:验证代码唯一性
- **当** 用户修改租户代码为已存在的代码
- **那么** 系统显示错误提示，代码已存在
