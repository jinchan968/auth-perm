# tenant-settings-page 规范

## 新增需求

### 需求:租户设置页必须显示当前设置
系统必须显示租户当前的设置信息。

#### 场景:查看租户设置
- **当** 用户进入租户设置页面
- **那么** 系统显示该租户的功能开关和配额设置

### 需求:租户设置页必须支持功能开关配置
系统必须支持配置功能开关。

#### 场景:配置功能开关
- **当** 用户切换功能开关并保存
- **那么** 系统更新功能开关设置

### 需求:租户设置页必须支持配额配置
系统必须支持配置用户配额、API配额等。

#### 场景:配置配额
- **当** 用户修改配额数值并保存
- **那么** 系统更新配额设置

### 需求:租户设置页必须验证配额数值
系统必须验证配额数值的有效性。

#### 场景:验证配额数值
- **当** 用户输入负数配额
- **那么** 系统显示错误提示，配额不能为负数
