# 租户管理前端 Design

## 上下文

当前前端项目使用 Next.js 构建，已有基本的页面结构。需要添加租户管理功能，包括列表页、详情页、创建/编辑页和设置页。

## 目标 / 非目标

**目标：**
- 实现租户列表页面（支持搜索、分页）
- 实现租户详情页面
- 实现租户创建/编辑表单
- 实现租户设置页面（功能开关、配额配置）

**非目标：**
- 计费相关功能
- 租户仪表盘统计

## 决策

### 1. 页面路由设计
**决策**：使用 `/app/tenants/` 作为路由基础

```
/app/tenants              - 租户列表
/app/tenants/new          - 创建租户
/app/tenants/[id]         - 租户详情
/app/tenants/[id]/edit    - 编辑租户
/app/tenants/[id]/settings - 租户设置
```

**理由**：遵循 Next.js App Router 的约定，与现有页面风格保持一致

### 2. API 调用方式
**决策**：使用 React Server Components + API Routes 方式

**理由**：项目已有的 API 调用方式，保持一致性

### 3. UI 组件
**决策**：复用现有的 UI 组件库（shadcn/ui）

**理由**：保持与现有页面风格一致

### 4. 表单验证
**决策**：使用 Zod 进行表单验证

**理由**：与项目现有验证方式保持一致

## 风险 / 权衡

1. **API 兼容性** → 需要确认后端 API 返回格式
2. **类型定义** → 需要为租户相关数据定义 TypeScript 类型
