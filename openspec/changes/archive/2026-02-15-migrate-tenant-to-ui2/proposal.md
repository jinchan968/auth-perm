# UI 迁移 Proposal

## 为什么

项目中存在两个前端目录 `ui`（旧版）和 `ui2`（新版）。租户管理功能已在 `ui` 中实现，需要迁移到 `ui2`，并将 `ui2` 替换为正式的 `ui` 目录，`ui` 目录标记为废弃。

## 变更内容

1. **迁移租户管理功能**：将 `ui` 中新增的租户管理页面和 API 复制到 `ui2`
2. **重命名目录**：`ui2` 目录重命名为 `ui`，原 `ui` 目录重命名为 `ui-deprecated`
3. **更新配置**：更新相关配置文件中的路径引用

## 功能 (Capabilities)

### 新增功能
- **tenant-migration**: 租户管理功能从 ui 迁移到 ui2
- **directory-rename**: 目录重命名和配置更新

### 修改功能
- (无)

## 影响

- `ui` 目录标记为废弃
- `ui2` 目录成为新的正式前端项目
- package.json 中的脚本和依赖需要更新
