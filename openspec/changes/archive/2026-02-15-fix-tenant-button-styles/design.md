## 上下文

当前租户详情页及子页面使用返回按钮时，按钮样式和 hover 态存在问题：
- 按钮颜色不够协调
- hover 态颜色变化不自然
- 与整体 UI 风格不一致

## 目标 / 非目标

**目标：**
- 优化返回按钮的基础样式（颜色、边框、圆角）
- 优化返回按钮的 hover 态效果
- 保持与整体 UI 风格一致

**非目标：**
- 不改变按钮的功能逻辑
- 不修改其他页面的按钮样式

## 决策

1. **使用 outline variant**：返回按钮使用 outline 样式，与主题色保持一致
2. **统一 hover 颜色**：使用 slat-100/200 替代当前的颜色
3. **使用 ArrowLeft 图标**：保持返回按钮的视觉一致性

## 风险 / 权衡

- 风险较低，仅涉及样式调整
- 已保留原 `/tenants/new` 页面不受影响
