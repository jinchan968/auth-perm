# 角色删除功能 - 技术设计

## 上下文

在角色详情页增加删除按钮，需要：
1. 调用后端已存在的删除接口
2. 添加确认对话框
3. 处理删除成功/失败的反馈

## 目标 / 非目标

**目标：**
- 在角色详情页添加删除按钮
- 点击后弹出确认对话框
- 确认后调用删除 API
- 删除成功跳转回列表页

**非目标：**
- 不修改后端接口（已存在）

## 决策

### UI 设计
- 删除按钮放置在页面右上角，与保存按钮相邻
- 使用 AlertDialog 组件实现确认对话框
- 删除按钮使用危险样式（红色）

### 交互流程
1. 用户点击删除按钮
2. 弹出确认对话框，显示角色名称
3. 用户确认后调用删除 API
4. 删除成功后跳转到 /permissions?tab=roles

## 风险 / 权衡

- 误删风险：通过确认对话框降低风险
- 权限检查：后端已处理租户隔离
