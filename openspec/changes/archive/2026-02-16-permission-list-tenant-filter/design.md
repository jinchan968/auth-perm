## 上下文

当前权限列表页面 (`app/permissions/page.tsx`) 使用 `user?.tenant_id` 获取当前用户的租户 ID 进行过滤。这种方式无法切换到其他租户。

现有代码：
- 已存在 `lib/api/tenant.ts` 提供 `listTenants` 函数
- 权限列表已有分页和关键词搜索功能

## 目标 / 非目标

**目标：**
- 在权限列表页面添加租户下拉选择器
- 支持搜索过滤租户名称
- 选择租户后自动刷新权限列表

**非目标：**
- 不修改其他页面（角色列表、用户角色分配等）
- 不添加默认租户选择（保持当前用户租户为默认）

## 决策

1. **UI 组件选择**: 使用 shadcn/ui 的 Select 组件
   - 已有 shadcn/ui 项目依赖
   - 支持搜索过滤功能

2. **默认选择**: 使用当前用户的 tenant_id 作为默认值
   - 如果用户有 tenant_id，默认选中该租户
   - 如果没有，显示"请选择租户"提示

3. **租户列表获取**: 使用现有的 `listTenants` API
   - 支持 keyword 参数过滤
   - 页面加载时获取租户列表

4. **状态管理**:
   - 添加 `selectedTenantId` state
   - 切换租户时重置分页到第一页

## 风险 / 权衡

- **租户列表为空**: 如果没有租户权限，显示提示信息
- **切换租户后权限为空**: 正常行为，显示"暂无数据"
