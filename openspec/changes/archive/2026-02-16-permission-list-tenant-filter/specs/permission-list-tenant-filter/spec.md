## 新增需求

### 需求:租户下拉选择器
权限列表页面必须显示租户下拉选择器，允许用户选择要查看的租户。

#### 场景:页面加载时获取租户列表
- **当** 用户打开权限列表页面
- **那么** 系统调用租户列表 API 获取可选租户
- **那么** 当前用户的租户被默认选中

#### 场景:用户选择租户
- **当** 用户从下拉菜单中选择一个租户
- **那么** 系统使用选中的租户 ID 过滤权限列表
- **那么** 权限列表自动刷新显示该租户的权限

#### 场景:搜索过滤租户
- **当** 用户在下拉搜索框中输入租户名称
- **那么** 系统调用租户列表 API 按名称过滤
- **那么** 下拉列表显示匹配的租户

### 需求:必选租户
用户必须选择租户才能查看权限列表。

#### 场景:未选择租户时禁止查看列表
- **当** 用户未选择任何租户
- **那么** 权限列表显示提示"请先选择租户"
- **那么** 搜索和分页功能禁用

#### 场景:默认选中用户租户
- **当** 当前登录用户有 tenant_id
- **那么** 默认选中该租户并自动加载权限列表
